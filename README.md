# Maison_De_Mode

The Maison de Mode Inventory and Billing Management System developed in Python provides a comprehensive solution for small and medium-sized stores to manage their stock, handle billing, and maintain accounting records efficiently. Built using the Tkinter graphical user interface (GUI) module, the system allows users to add, view, and update inventory, generate invoices with GST, and track profit or loss automatically.

#Tech Stack

**Language**: Python
**Libraries used:** tkinter, csv, reportlab, datetime, os, ttk, messagebox
